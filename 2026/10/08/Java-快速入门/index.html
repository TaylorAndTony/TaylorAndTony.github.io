FunctionalInterface 函数式接口是 Java 8 引入的一种新特性，它是一个有且仅有一个抽象方法的接口，但可以有多个非抽象方法。函数式接口可以被隐式转换为 lambda 表达式，使得代码更加简洁和易读。

Thread 和 Runnable 的区别：

  • Runnable 是接口：代表要执行的任务，里面只有一个 run() 方法，描述线程要做什么。
  • Thread 是类：代表线程本身，负责创建、启动、管理线程。Thread 类本身也实现了 Runnable。

优点：只是实现接口，不占用继承位；同一个任务对象可以交给多个线程执行。
